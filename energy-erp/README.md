# California Grid ERP — Synthetic Demo

A standalone, frontend-only energy utility ERP derived from the VLCI ERP user interface.

## Run

```bash
npm run dev
```

Open http://localhost:5182. There is no sign-in screen and no backend or database is required.

All names, accounts, addresses, meter readings, financial records, grid assets, and operational events are deterministically generated synthetic demo data. They do not represent PG&E or any real customer.
